description=Tracing that just works: ArcGIS Pro-style tracing along all visible line and polygon layers – draw new features or split existing ones, no snapping setup needed.
about=Click on a line and move the mouse: the shortest path along the visible line and polygon layers is traced and remembered as you go, so it does not jump to a nearby road or boundary. Click off the lines to add freehand vertices – tracing and freehand mix freely. Unlike QGIS' built-in tracing (T), Pro Trace does not depend on the project's snapping settings: it uses its own snapping on vertices and edges of every visible layer and nodes the lines itself, so it also works when lines nearly overlap. Draws into the active line or polygon layer (starts editing automatically). Pro Trace Split uses the same tracing to cut existing features: trace across them and press Enter, like QGIS' Split Features tool – only selected features are split when there is a selection, and Ctrl+Z undoes it. Enter or right click saves, Backspace undoes, Esc cancels. Built for QGIS 4 (Qt6), also runs on QGIS 3.34 and newer.
