description=Stream cross-section surveys: read the field file (Emlid Flow and others), build stationing and cross-sections, and extend each section onto terrain with a terrain model.
about=For regulation and maintenance surveys of streams. Reads the surveyor's field file – Emlid Flow CSV, shapefile and DXF, other CSV or text files, or a point layer in the project – and translates the survey codes with an editable code table; VASP/VASPGPS codes are recognised and paired automatically, and VASP surveys are interpreted as VASPGPS does (sections from start to end code, section line through the edge marks, stream line through mid points and break points). Builds the stream centre line (or uses an existing one), stationing downstream from a fixed point and cross-sections perpendicular to the centre line, with station, offset and side for every point. Each section is extended from the outermost bank top onto terrain with Danmarks Højdemodel (your own Dataforsyningen token, kept in the QGIS password manager) or a local terrain model; every point keeps its source (measured, terrain model or transition) and differences at the bank top are flagged. Everything is stored in one GeoPackage per survey. User interface in English and Danish. Built for QGIS 4 (Qt6), also runs on QGIS 3.40.
